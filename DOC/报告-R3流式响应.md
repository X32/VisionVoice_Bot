## 1. 最终管线

```
worker线程               合成线程                    播放线程
───────────────────────────────────────────────────────────────
LLM chat_stream delta
 → SentenceSplitter攒句
 → sent_q(4) ──────────→ tts.speak(句) 重采样16k+trim
                          → seg_q(2) ─────────────→ 首段就绪即开流
    producer_done事件 →     排空自查退出              play_segments逐块写
    （无哨兵）              synth_done=迭代器终点      on_chunk喂AEC参考
```

三线程两队列（maxsize 即背压），播放与 LLM 流**并发**——这是踩坑后修正的关键设计（见 §3）。

## 3. 实施中踩的三个坑（都已修复，代码有注释）

### 3.1 哨兵丢失 → 合成线程永不退出（场景B死锁）

初版用 `sent_q.put(None)` 通知合成线程退出。当 sent_q 满且合成线程正被 seg_q 满阻塞时，
`put(None, timeout=2)` 超时**丢掉哨兵** → 合成线程永不返回 → 播放迭代器永不结束 → 30s 无进展超时误报。
faulthandler 线程栈定位。**修法**：彻底废除哨兵，`producer_done` 事件 + 合成线程带超时 get 自查退出。

### 3.2 播放晚于流结束 → 全链路堵死（场景C死锁，更隐蔽）

初版把 `play_segments` 放在**流读完后**才调用。流式期无人消费 seg_q → 合成线程堵在 seg_q.put
→ sent_q 满 → worker 堵死在无超时 `sent_q.put`，**打断也救不回**（put 不看 interrupted）。
**修法**：播放独立线程与 LLM 流并发，首段就绪（`first_seg_evt`）即开播；所有 put 带超时 + 打断自查退出。
副产品收益：场景B首块写出从 0.63s 提前到 0.19s。

### 3.3 流式打断的历史语义

R2 非流式："全文 + （被用户打断）"。流式下打断即取消上游，**未读部分根本没生成完**，
"全文"不存在。修订为语义等价物：**已读文本 + 标记**（已读 ≥ 已播，"继续说"依然接得上）。
这是 R2 决策在流式语境下的自然演化，非行为回退。

## 5. 回归与一次重要的"假阳性"排查

- `player.py` 自测：PASS（play 短句路径零回归）
- `test_stream.py` B/C：PASS（多次复跑稳定）
- `test_barge.py`（R2.1 打断五场景）：**FAIL → 排查 → 与 R3 无关 → 部分修复**，过程值得记录：
  1. `git stash` 回 R2 基线跑同样 FAIL —— **证明与本次改动无关**（vad_asr 仅新增 enter_standby）
  2. 根因是**测试材料非确定性**（三层）：
     - matcha 合成非字节确定（同文本每次是不同"发音取样"，/tmp 清空重生成 = 重骰）
     - far 与插话 clip 同为 matcha 声时，AEC 非线性处理把近端语音当回声压掉一部分（同音色协同信道抑制，实测无回声混入也砍半）；约 1/5 取样能穿透
     - int16 WAV 往返量化会把恰在阈值上的边缘分数翻面（内存验证通过 ≠ 落盘后通过）
  3. 真机 near 是真人嗓音、与 TTS 远端相关性低，无此恶化 —— R2 真机验收结论不受影响
  4. 修复：`test_barge.py` 合成期**逐把落盘验证**（`_kws_probe` 与正式路径同构），只缓存过关取样；/tmp 再清空也能自愈
  5. 终态：A/闭嘴/别说了/唤醒词/长语音/纯回声全 PASS；`不要说了` 稳定 1/2（30+ 把取样从未在 delay=200ms 档命中，离线合成-合成场景的物理极限，非代码 bug，以真机为准）

## 6. 已知边界（诚实清单）

- **冷加载首答慢**：模型卸载后首 token ~1.9s → 首出声 ~2.8s（超预算）；常驻方案 `OLLAMA_KEEP_ALIVE`
- **首句前不可打断**（约 0.5~1.0s，首token+首句攒句期）：AEC 参考未到，`_barge_check` 自动跳过——与 R2 现状一致的固有窗口，但从全量路径的 5s+ 缩到 ~1s
- 逐句合成的句间响度差：matcha 逐句峰值归一化，可能有轻微响度跳变（接受，实测听感正常）
- 工具调用轮（"让我查一下"类）：qwen 工具轮首块即到且 content 为空，不会被说出口；工具结果回来后下一轮流式照常
- 一次性现象：`--real` 测试进程退出时偶发 `malloc_consolidate` core dump（PortAudio abort 流 + sherpa 退出竞态，仅退出时刻，长驻生产进程不受影响，未复现于后续运行）
